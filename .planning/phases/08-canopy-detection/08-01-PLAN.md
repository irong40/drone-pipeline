<task type="auto">
  <name>Task 2: Tiling engine, DeepForest inference, and NMS</name>
  <files>canopy_detection.py</files>
  <action>
Add the core detection logic to canopy_detection.py:

**1. GeoTIFF tiling:**
- Open ortho with rasterio.open(), read CRS and transform matrix
- Calculate tile grid: number of tiles in x/y based on tile_size and image dimensions
- For each tile: compute window with overlap (128px default on each side, clamped at edges)
- Read tile as numpy array via dataset.read(window=window)
- Track tile coordinates (row_off, col_off) for geographic transform later

**2. DeepForest inference:**
- Initialize: `model = deepforest.main.deepforest(); model.use_release()`
- Move to CUDA: `model.model.to("cuda")`
- Per tile: convert numpy array to format DeepForest expects (it expects RGB uint8)
- Use `model.predict_tile()` if available for built-in tile handling, OR manually feed tiles
- Actually, use `model.predict_image()` on each tile array — predict_tile does its own tiling which we don't want since we already tile
- Extract bounding boxes: xmin, ymin, xmax, ymax, confidence, label

**3. Pixel-to-geographic transform:**
- For each bounding box, convert pixel coords to geographic coords using rasterio transform:
  ```python
  from rasterio.transform import xy
  # Box coords are relative to tile window — add tile offset first
  geo_xmin, geo_ymin = xy(dataset.transform, row_off + ymin, col_off + xmin)
  geo_xmax, geo_ymax = xy(dataset.transform, row_off + ymax, col_off + xmax)
  ```
- Create Shapely box polygon for each detection
- Calculate centroid (lat/lon), area (sqm), width, height using CRS units

**4. Cross-tile NMS:**
- Collect ALL detections from ALL tiles into one list
- For each pair of overlapping polygons:
  ```python
  iou = poly_a.intersection(poly_b).area / poly_a.union(poly_b).area
  if iou > iou_threshold:
      keep higher confidence, drop lower
  ```
- Use an efficient approach: sort by confidence descending, iterate and suppress
- Result: deduplicated list of canopy polygons

**Memory management:**
- Process tiles one at a time, don't hold all tile arrays in memory
- Delete tile numpy arrays after inference: `del tile_data`
- Use torch.cuda.empty_cache() periodically if memory pressure detected
- GDAL_CACHEMAX already set to 256MB at startup
