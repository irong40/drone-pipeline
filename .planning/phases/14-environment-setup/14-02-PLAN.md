"""Minimal test script for n8n Execute Command verification.

2. Create `n8n/` directory under drone-pipeline if it does not already exist (for storing n8n workflow JSONs used by this project).

3. Create `n8n/14-env-verification.json` -- a complete, valid n8n workflow JSON that can be imported via n8n UI (Settings > Import from File). The workflow must have:

   a. A **Manual Trigger** node (start node)
   b. An **Execute Command** node that runs:
      - If native Windows: `python "C:\Users\redle.SOULAAN\Documents\drone-pipeline\verify_n8n.py"`
      - Use `$env.SENTINEL_SCRIPTS` to build the path dynamically: `python "{{ $env.SENTINEL_SCRIPTS }}\\verify_n8n.py"`
      - Adjust path separators based on architecture decision in 14-01-SUMMARY.md
   c. A **Code** node (typeVersion 2) with this JavaScript:
      ```javascript
      const vars = [
        'MIPMAP_ENGINE_PATH',
        'MIPMAP_WORKSPACE',
        'SENTINEL_INCOMING',
        'SENTINEL_SCRIPTS',
        'VENV_PATH_E_PYTHON',
        'N8N_BASE_URL'
      ];
      const results = {};
      let allPresent = true;
      for (const v of vars) {
        const val = $env[v] || 'MISSING';
        results[v] = val;
        if (val === 'MISSING') allPresent = false;
      }
      results.all_present = allPresent;
      results.timeout = $env.EXECUTIONS_TIMEOUT || 'NOT SET';
      results.timeout_max = $env.EXECUTIONS_TIMEOUT_MAX || 'NOT SET';
      return [{ json: results }];
      ```
   d. Wire: Manual Trigger -> Execute Command -> Code node
   e. Include proper `meta`, `nodes`, `connections`, and `settings` structure so n8n accepts the import

4. Validate the JSON file is parseable: `python -c "import json; json.load(open('n8n/14-env-verification.json'))"`
