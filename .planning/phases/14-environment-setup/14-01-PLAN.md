<task type="checkpoint:decision" gate="blocking">
  <name>Task 1: Decide Docker vs Native n8n</name>
  <decision>Should n8n continue running in Docker or switch to native Windows install?</decision>
  <context>
Research found that n8n runs in Docker (Alpine Linux) with NO Python installed and NO volume mounts to host drives. All existing workflow JSONs use Windows paths (E:\Sentinel\...). GPU (CUDA) is needed for Path E scripts. Docker adds a translation layer that creates ongoing friction.

Current Docker state:
- n8n 2.10.3 in Alpine 3.22 container
- No Python in container
- No volume mounts to E:\, D:\, F:\, or scripts directory
- Existing workflows reference Windows paths

The research STRONGLY recommends native Windows install (npm install -g n8n).
  </context>
  <options>
    <option id="native">
      <name>Native Windows install (RECOMMENDED)</name>
      <pros>Execute Command runs in Windows shell with full Python/GPU/drive access. All existing workflow paths work unchanged. No container path translation. CUDA accessible for Path E.</pros>
      <cons>No container isolation. Must manage n8n process manually (Task Scheduler or nssm). Port 5678 conflict with Docker n8n must be resolved first.</cons>
    </option>
    <option id="docker-custom">
      <name>Custom Docker image with Python + volume mounts</name>
      <pros>Container isolation maintained. Familiar Docker workflow.</pros>
      <cons>Must build custom Dockerfile. Must rewrite ALL workflow paths from Windows to Linux container paths. Must mount E:\, D:\, F:\ as volumes. GPU passthrough via Docker is complex. PyTorch/rasterio install in Alpine is painful.</cons>
    </option>
    <option id="docker-keep">
      <name>Keep current Docker (env vars only, defer Execute Command)</name>
      <pros>Minimal change. Env vars and timeout work in Docker. Defers Execute Command problem.</pros>
      <cons>ENV-01 (Execute Command verification) cannot be fully verified. Kicks the problem to Phase 15 where it becomes a blocker.</cons>
    </option>
  </options>
  <resume-signal>Select: native, docker-custom, or docker-keep</resume-signal>
