Priority chain (execute in this exact order, return on first match):

Step 1 - Opt-out check:
  - Define OPT_OUT_KEYWORDS = ["stop", "unsubscribe", "opt out", "opt-out", "cancel"]
  - If message.textBody and textBody.toLowerCase().trim() matches any keyword:
    - Update client: set opted_out=true, opted_out_at=now in clients table
    - Log to activity_log: event_type "client_opted_out", payload { phone, keyword }
    - Return { handler: "opt_out", shouldRespond: true, responseText: "You have been unsubscribed. Reply START to re-subscribe." }

Step 2 - Manual mode check:
  - If client.manual_mode is true:
    - Log to activity_log: event_type "manual_forward", payload { phone, clientId }
    - Return { handler: "manual_forward", shouldRespond: false, forwardTo: "adam" }

Step 3 - After-hours check:
  - If NOT isBusinessHours():
    - Log to activity_log: event_type "after_hours_message", payload { phone }
    - Return { handler: "after_hours", shouldRespond: true, responseText: "Thanks for reaching out! Our team is available Mon-Fri 8AM-6PM ET. We'll respond first thing next business day." }

Step 4 - Media routing:
  - If message.type !== "text" and message.mediaId is not null:
    - Return { handler: "vision", shouldRespond: false }

Step 5 - Text routing (default):
  - Return { handler: "llm", shouldRespond: false }
