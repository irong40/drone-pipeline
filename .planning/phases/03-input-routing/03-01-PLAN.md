supabase/functions/_shared/hmac.ts:
- Export async function verifyHmacSignature(body: string, signatureHeader: string, secret: string): Promise of boolean
- Parse the "sha256=..." prefix from signatureHeader
- Use Web Crypto API (crypto.subtle.importKey + crypto.subtle.sign) to compute HMAC-SHA256
- Compare computed hash with provided hash using timing-safe comparison (convert both to Uint8Array, compare byte-by-byte, constant time)
- Do NOT use Node.js crypto module -- use Deno/Web Crypto API only

supabase/functions/_shared/client-lookup.ts:
- Export async function findOrCreateClient(phone: string, displayName?: string): Promise of Client
- Query clients table by phone using supabaseAdmin
- If found, return existing client
- If not found, insert new client with phone and name (from displayName or null), return the new record
- Log to activity_log: event_type "client_identified" (existing) or "client_created" (new) with { phone } payload

supabase/functions/whatsapp-webhook/index.ts:
- Import { serve } from "https://deno.land/std@0.168.0/http/server.ts" (or use Deno.serve for newer runtime)
- Handle GET: verify hub.mode === "subscribe" and hub.verify_token matches WHATSAPP_VERIFY_TOKEN env var. Return hub.challenge as plain text 200 or 403.
- Handle POST: read raw body as text, verify HMAC using X-Hub-Signature-256 header and WHATSAPP_APP_SECRET env var. If invalid, return 401 { error: "Invalid signature" }.
- Parse body as WhatsAppWebhookPayload. Extract messages from entry[0].changes[0].value.messages. If no messages, return 200 (Meta sends status updates too).
- For each message: extract WhatsAppMessage fields. Call findOrCreateClient(message.from, contact.profile.name).
- For now, return 200 { status: "received", clientId }. Routing chain (Plan 02) will add the priority chain.
- Log to activity_log: event_type "webhook_received" with message summary.
