```python
def crop_canopy(dataset, polygon_wkt, padding_pct=0.15):
    """Crop a canopy polygon from the orthomosaic with padding.

    Args:
        dataset: open rasterio dataset
        polygon_wkt: WKT string of canopy polygon
        padding_pct: fractional padding around bounding box (0.15 = 15%)

    Returns:
        PIL.Image resized to max 512px on longest dimension, or None on failure
    """
```
- Parse WKT to shapely polygon
- Get bounding box, expand by padding_pct on each side
- Use rasterio.mask.mask() with crop=True to extract pixels
- Convert numpy array (bands, h, w) to PIL Image (RGB)
- Resize to 512px max dimension preserving aspect ratio (Pillow LANCZOS)
- Return PIL Image

**1. OpenAI Vision classification function:**
```python
def classify_openai(image: Image, api_key: str) -> dict:
```
- Encode PIL Image as base64 PNG
- Send to openai.chat.completions.create() with model="gpt-4o"
- System message: certified arborist identifying from aerial drone imagery
- User message with image_url (base64 data URI) + the full Hampton Roads species prompt from the PRD (20 species list: Loblolly Pine, Live Oak, Red Maple, Sweetgum, Eastern Redcedar, Bald Cypress, Southern Magnolia, Tulip Poplar, Willow Oak, American Holly, Virginia Pine, White Oak, Black Cherry, River Birch, Eastern White Pine, American Sycamore, Crape Myrtle, Wax Myrtle, Leyland Cypress, Sabal Palmetto)
- Request JSON response with: species_common, species_scientific, vegetation_type, confidence, reasoning, secondary_candidates
- Parse response, handle JSON parse failures gracefully (retry once, then mark as "unidentified")
- Return parsed dict

**2. PlantNet classification function:**
```python
def classify_plantnet(image: Image, api_key: str) -> dict:
```
- Save PIL Image to temp PNG file
- POST multipart form to https://my-api.plantnet.org/v2/identify/all
- Params: project="useful", organs=["leaf"] (canopy top-down view)
- Headers: Api-Key from env var PLANTNET_API_KEY
- Parse response: extract top species name, score, and full results list
- Check X-Remaining-Identifications header — log warning if below 10
- Return dict with species name, score, full_results
- Return None if --skip-plantnet

**3. Confidence reconciliation function:**
```python
def reconcile(openai_result: dict, plantnet_result: dict | None) -> dict:
```
- If plantnet_result is None (skipped): return openai result as-is
- Extract genus from both: first word of species_common (e.g., "Loblolly" from "Loblolly Pine")
  Actually, use species_scientific: genus = scientific_name.split()[0]
  For PlantNet: genus from their top result scientific name
- If genus matches: confidence = min(openai_confidence + 0.1, 1.0), cross_validated = True
- If genus differs: confidence = max(openai_confidence - 0.15, 0.0), cross_validated = False
- Store both full API responses in classification_details JSONB:
  ```python
  {
      "openai": openai_result,
      "plantnet": plantnet_result,
      "reconciliation": {"genus_match": bool, "adjustment": float}
  }
  ```
- Return: species_tag (openai species_common), species_confidence, vegetation_type, cross_validated, classification_details
