**Health score formula:**
```python
def compute_health_score(indices):
    # Normalize mean_vari from [-1,1] to [0,1]
    vari_norm = (indices["mean_vari"] + 1) / 2
    exg_norm = max(0, min(1, (indices["mean_exg"] + 1) / 2))
    score = (vari_norm * 0.3 + exg_norm * 0.2 +
             indices["green_fraction"] * 0.3 +
             (1 - indices["stress_fraction"]) * 0.2)
    return round(max(0, min(1, score)), 3)
```

**Status categorization:**

def health_status(score):
    if score > 0.7: return "healthy"
    if score > 0.5: return "moderate_stress"
    if score > 0.3: return "stressed"
    if score > 0.15: return "severe_decline"
    return "dead"
