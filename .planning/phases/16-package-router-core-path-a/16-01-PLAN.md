Standard Supabase headers (apikey + Authorization from $env.SUPABASE_SERVICE_KEY). Position [960, 200]. After this, use a Code node to merge mission_id back:

5. **"Merge Mission ID"** — n8n-nodes-base.code (typeVersion 2). JS code: Takes the lookup result and merges mission_id (and address, city) into the normalized payload. If lookup returns empty array, set mission_id to null. Code:
```javascript
const lookup = items[0].json;
const prev = $('Normalize Payload').first().json;
const mission = Array.isArray(lookup) ? lookup[0] : lookup;
return [{json: {
  ...prev,
  mission_id: mission?.id || prev.mission_id,
  address: mission?.address || '',
  city: mission?.city || '',
  needs_mission_lookup: false
}}];
```
Position [960, 200].

NOTE: For the "false" branch of the IF node (ingest_sorter payloads that already have mission_id), we need to also fetch address/city. Create:

5c. **"Merge Address"** — n8n-nodes-base.code (typeVersion 2). Merges address/city from lookup into the payload. Position [1200, 400].

7. **"IF Duplicate Exists"** — n8n-nodes-base.if (typeVersion 2). Condition: Check if the response array is NOT empty (length > 0). If duplicate exists (true branch) -> stop. If no duplicate (false branch) -> continue. Position [1680, 300].
