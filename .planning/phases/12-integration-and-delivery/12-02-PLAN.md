Document the review gate webhook contract that n8n's webhook wait node expects. This is handled by n8n's built-in webhook resume, but the decisions array format must be documented for the admin UI to POST correctly.

Add a docstring/comment block in delivery_packaging.py or a separate REVIEW_GATE.md:

**Webhook endpoint:** POST /sentinel-vegetation-resume (n8n webhook wait node)
**Request body:**
```json
{
    "mission_id": "uuid",
    "decisions": [
        {"detection_index": 0, "action": "approve"},
        {"detection_index": 5, "action": "exclude", "reason": "false positive"},
        {"detection_index": 12, "action": "flag_arborist", "notes": "possible disease"}
    ]
}
```

**Actions:**
- approve: Keep detection in report (default if not in decisions array)
- exclude: Remove from report, mark review_status='excluded' in Supabase
- flag_arborist: Keep in report with "arborist recommended" flag, mark review_status='flagged'

**After decisions processed:** n8n re-runs E4 (vegetation_report.py) to regenerate PDF/maps excluding excluded detections. Then calls delivery_packaging.py.

The admin UI that sends this POST is in the Trestle app (separate project — out of scope for pipeline). Document the contract so it can be implemented there later.
