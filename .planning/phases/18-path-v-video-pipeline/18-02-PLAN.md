4. **IF V1 Failed** (if) - Check exitCode != 0; TRUE -> Stop on V1 Failure; FALSE -> continue

5. **Execute V1.5 Metadata** (executeCommand) - Run video_metadata.py with folder_path, --platform, --mission-id, --upload, --processing-job-id
6. **Parse V1.5 Result** (code) - Extract exitCode, merge, set v1_5_exit_code
7. **IF V1.5 Failed** (if) - TRUE -> Stop on V1.5 Failure; FALSE -> continue

8. **Execute V2 SRT** (executeCommand) - Run srt_telemetry_parser.py
9. **Parse V2 Result** (code) - Extract exitCode, merge, set v2_exit_code
10. **IF V2 Failed** (if) - TRUE -> Stop on V2 Failure; FALSE -> continue

11. **Execute V3 QA** (executeCommand) - Run video_qa.py with --mission-id and --mission-path
12. **Parse V3 Result** (code) - Extract exitCode, merge, set v3_exit_code
13. **IF V3 Failed** (if) - TRUE -> Stop on V3 Failure; FALSE -> continue

14. **Execute V4 Proxy Gen** (executeCommand) - Run video_proxy_gen.py
15. **Parse V4 Result** (code) - Extract exitCode, merge, set v4_exit_code
16. **IF V4 Failed** (if) - TRUE -> Stop on V4 Failure; FALSE -> continue

17. **V5 Gate Setup** (code) - Set v5_status to 'awaiting_manual_edit', output message with resume URL info for operator. Use the pattern from 18-RESEARCH.md Code Examples.

21. **Parse V6 Result** (code) - Extract exitCode, merge, set v6_exit_code
22. **IF V6 Failed** (if) - TRUE -> Stop on V6 Failure; FALSE -> continue
