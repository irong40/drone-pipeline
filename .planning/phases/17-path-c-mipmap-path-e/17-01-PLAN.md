  <name>Task 1: Create Path C sub-workflow JSON</name>
  <files>n8n/path_c_workflow.json</files>
  <action>
Create n8n/path_c_workflow.json following the exact same structure as path_a_workflow.json (entry point, settings, _meta) combined with path_e_workflow.json polling loop pattern. The workflow id MUST be "sentinel-path-c".

Node sequence (all positions on y=300 main line unless noted):

1. **Execute Sub Workflow Trigger** (node-trigger, [240, 300]) - Entry point from Package Router. Same as path_a_workflow.json trigger. Notes document expected payload.

2. **C1 -- Launch MipMap** (node-c1-launch, [480, 300]) - Execute Command:
   `python "{{ $env.SENTINEL_SCRIPTS }}\\mipmap_launcher.py" --mission-id {{ $json.mission_id }} --mission-path "{{ $json.folder_path }}" --processing-job-id {{ $json.processing_job_id }}`

3. **C1 -- Parse Launch Result** (node-c1-parse, [720, 300]) - Code node. Parse mipmap_launcher.py stdout JSON. Extract workspace_path if present. Check exitCode. Pass through all trigger params. If exitCode != 0, set launch_failed=true.

4. **C1 -- Launch Failed?** (node-c1-if-failed, [960, 300]) - IF node checking launch_failed == true (or exitCode != 0). TRUE output [960, 100] -> Stop on Failure node. FALSE output -> C2 polling loop.

5. **Stop on Failure** (node-stop-failure, [1200, 100]) - Code node returning { status: 'failed', failed_step, exit_code, mission_id }. Same pattern as path_a_workflow.json.

6. **C2 -- Build Ortho Path** (node-c2-build-path, [1200, 300]) - Code node. Mirror the E0 -- Build Ortho Path pattern from path_e_workflow.json:
   - Get mission_id from trigger
   - Construct ortho check path: `$env.MIPMAP_WORKSPACE + '\\' + mission_id + '\\result'`
   - Use `dir /b` command target (check for *.tif in result dir, not hardcoded filename -- MipMap output name is uncertain)
   - Track poll_attempt via $getWorkflowStaticData('global')
   - Return { mission_id, ortho_check_dir, mission_path, processing_job_id, poll_attempt, max_attempts: 120 }

7. **C2 -- Check Ortho Exists** (node-c2-check-exists, [1440, 300]) - Execute Command:
   `if exist "{{ $json.ortho_check_dir }}\\*.tif" (echo FOUND) else (echo MISSING)`
   NOTE: Windows `if exist` supports wildcards. This checks for any .tif in the result directory.

8. **C2 -- Ortho Found?** (node-c2-ortho-found, [1680, 300]) - IF node: $json.stdout.trim() == "FOUND". TRUE -> C3 Harvest. FALSE -> Max Attempts check.

9. **C2 -- Max Attempts?** (node-c2-max-attempts, [1680, 480]) - IF node: poll_attempt >= 120. TRUE -> C2 -- Set Failed (Timeout). FALSE -> Wait.

10. **C2 -- Set Failed (Timeout)** (node-c2-timeout, [1920, 600]) - Code node. Return { status: 'failed', reason: 'mipmap_timeout', poll_attempts: N, mission_id }. Log that MipMap did not produce output within 2 hours.

11. **C2 -- Wait 60s** (node-c2-wait, [1920, 480]) - Wait node: amount=60, unit=seconds. Connects back to C2 -- Build Ortho Path to create the polling loop.

12. **C3 -- Find Ortho File** (node-c3-find-ortho, [1920, 300]) - Execute Command:
   `dir /b "{{ $('C2 -- Build Ortho Path').item.json.ortho_check_dir }}\\*.tif"`
   This gets the actual filename of the GeoTIFF (since we don't know if it's orthomosaic.tif or dom.tif).

13. **C3 -- Build Harvest Command** (node-c3-build-harvest, [2160, 300]) - Code node. Construct the full source path by combining ortho_check_dir + stdout filename from dir command. Return { source_path, mission_path, mission_id, processing_job_id }.

14. **C3 -- Harvest Ortho** (node-c3-harvest, [2400, 300]) - Execute Command:
   `python "{{ $env.SENTINEL_SCRIPTS }}\\ortho_harvester.py" --source-path "{{ $json.source_path }}" --mission-path "{{ $json.mission_path }}" --mission-id {{ $json.mission_id }} --processing-job-id {{ $json.processing_job_id }}`

15. **C3 -- Parse Harvest Result** (node-c3-parse-harvest, [2640, 300]) - Code node. Parse ortho_harvester.py stdout JSON. Check exitCode. If failed, route to stop. Pass through mission_id, processing_job_id.

16. **C3 -- Harvest Failed?** (node-c3-if-failed, [2880, 300]) - IF node: exitCode != 0. TRUE -> Stop on Failure. FALSE -> C4 vegetation check.

17. **C4 -- Check Vegetation Flag** (node-c4-check-veg, [3120, 300]) - HTTP Request node. GET from Supabase drone_jobs where id=eq.{mission_id}, select vegetation_analysis. Use Option B from research (direct Supabase check). Same header pattern as path_e_workflow.json's E0 -- Check Mission node.

18. **C4 -- Vegetation Enabled?** (node-c4-if-veg, [3360, 300]) - IF node: $json[0].vegetation_analysis == true. TRUE -> Trigger Path E. FALSE -> Done (Code node at [3360, 480] returning { status: 'complete', vegetation_triggered: false }).

19. **C4 -- Trigger Path E** (node-c4-trigger-e, [3600, 300]) - HTTP Request POST to `{{ $env.N8N_BASE_URL }}/webhook/sentinel-vegetation-trigger` with body `{ "mission_id": "{{ mission_id }}" }`. Use sendBody=true, contentType=json.

20. **C4 -- Path C Complete** (node-c4-complete, [3840, 300]) - Code node returning { status: 'complete', vegetation_triggered: true, mission_id }.

Connections (follow the exact n8n connections format from path_a_workflow.json):
- trigger -> C1 launch
- C1 launch -> C1 parse
- C1 parse -> C1 if failed
- C1 if failed: TRUE[0] -> stop failure, FALSE[1] -> C2 build path
- C2 build path -> C2 check exists
- C2 check exists -> C2 ortho found
- C2 ortho found: TRUE[0] -> C3 find ortho, FALSE[1] -> C2 max attempts
- C2 max attempts: TRUE[0] -> C2 timeout, FALSE[1] -> C2 wait
- C2 wait -> C2 build path (LOOP)
- C3 find ortho -> C3 build harvest
- C3 build harvest -> C3 harvest
- C3 harvest -> C3 parse harvest
- C3 parse harvest -> C3 if failed
- C3 if failed: TRUE[0] -> stop failure, FALSE[1] -> C4 check veg
- C4 check veg -> C4 if veg
- C4 if veg: TRUE[0] -> C4 trigger E, FALSE[1] -> C4 done (no veg)
- C4 trigger E -> C4 complete

Settings: Copy from path_a_workflow.json (executionOrder v1, saveManualExecutions true, callerPolicy workflowsFromSameOwner, timezone America/New_York).
