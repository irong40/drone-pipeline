def test_find_source_videos_prefers_graded(tmp_path):

**Key facts from source inspection:**
- `build_ffmpeg_command(input_path, output_path, fmt, source_duration=None)`
- `fmt` dict keys: `name`, `resolution`, `codec`, `fps` (default 30), `max_duration_sec` (optional)
- copy codec path: `-c:v copy -c:a copy` — NO `-vf` scale filter in output
- libx264/libx265 path: `-vf scale=W:H:...,pad=... -c:v codec -crf 18 -preset medium -r fps -c:a aac -b:a 192k`
- Duration truncation: `-t max_dur` inserted after `-i input` — only when `source_duration > max_dur`
- Invalid resolution raises `ValueError("Invalid resolution format: ...")`
- `get_video_duration` parses `{"format": {"duration": "30.0"}}` from ffprobe stdout
- `find_master_video` looks in `video/master/` directory for MP4/MOV files
