<objective>
Standardize exit codes and fatal error handling across all 5 video pipeline scripts.

Purpose: n8n orchestration reads exit codes to determine whether to retry, alert, or continue. Currently scripts exit 0 on failure (no exit call) or exit 1 for both fatal and partial failures (sys.exit("string")). n8n cannot distinguish "FFmpeg not found" from "5 of 10 files failed" — both look the same. After this plan: 0=full success, 1=partial (some ok some failed), 2=fatal (nothing succeeded or configuration error).
Output: 5 scripts with consistent exit behavior and no string-argument sys.exit() calls.
</objective>
